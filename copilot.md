# Copilot Instructions — Unity 6 2D Dual-Character Platformer

## Project Overview

This is a Unity 6 2D platformer featuring two simultaneously controlled characters:
- **Princess**
- **Monster**

The player controls both characters at the same time using separate input schemes:
- Princess → WASD
- Monster → Arrow Keys

Both characters exist in the same world and must cooperate to solve puzzles, traverse platforms, and interact with physics-based systems.

The core gameplay revolves around:
- Dual-character coordination
- Puzzle-solving that requires both entities
- Precision platforming with shared environment interactions
